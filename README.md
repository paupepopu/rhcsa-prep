# RHCSA Certification Study Notes

Study notes for the **Red Hat Certified System Administrator (RHCSA)** exam
(EX200), organized around Red Hat's official exam objectives and built while
completing Sander van Vugt's RHCSA course (Pearson IT Certification).

## Structure

Notes are organized by exam objective category, following the official
breakdown published by Red Hat:
<https://www.redhat.com/en/services/training/ex200-red-hat-certified-system-administrator-rhcsa-exam>

```bash
rhcsa-prep/
├── README.md
├── TEMPLATE.md
├── progress-log.md
├── 01-essential-tools/
├── 02-software-management/
├── 03-shell-scripting/
├── 04-operating-running-systems/
├── 05-local-storage/
├── 06-file-systems/
├── 07-deploy-configure-maintain-systems/
├── 08-basic-networking/
├── 09-users-and-groups/
└── 10-security/
```

Each folder contains a `notes.md` following the format in
[`TEMPLATE.md`](./TEMPLATE.md).

## Course Reference

- Course: RHCSA Complete Video Course — Sander van Vugt (Pearson IT Certification)
- Exam: Red Hat Certified System Administrator (EX200)

## Lab Environment

- **Hypervisor:** VMware Workstation Pro
- **RHEL Version:** RHEL 10.2
- **VM Specs:** 2 vCPU, 4GB RAM, 20GB disk
- **Network Setup:** NAT
- **Number of VMs:** 1 primary (may add a 2nd later for networking/NFS/SSH practice)
